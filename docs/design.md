# 动态分辨率与时域放大设计说明

本项目在一个小型 DX11 PBR 场景上实现动态分辨率（Dynamic Resolution）与时域
放大（Temporal Anti-Aliasing Upscaling, TAAU），并提供一个与渲染器共享同一
算法核心的可运行 CPU 仿真台用于量化评估。

## 1. 目录与共享核心

- `src/renderer/shaders/temporal_core.hlsli`：与 API 无关的时域算法核心，
  使用 HLSL/C++ 公共子集编写。HLSL 直接 `#include`；C++ 通过
  `src/sim/shim_cpp.h` 注入 `float2/3/4` 等类型后编译同一份文件，保证仿真
  与真机着色器的算法逐行一致，不存在“两份实现漂移”。
- `src/renderer/`：DX11 应用（设备封装、PBR G-buffer、compute 放大、GPU 计时）。
- `src/sim/`：光线投射 PBR 场景与三模式基准台，本环境可直接运行。

## 2. 抖动与坐标变换

### 2.1 子像素抖动

Halton(2,3) 8 帧循环，`JitterOffsetPx` 返回 `[-0.5, 0.5)` 像素的归一化偏移。
渲染器在投影矩阵的 NDC 平移项注入抖动；仿真台则把抖动加到光线采样位置。

### 2.2 当前帧与历史帧坐标

统一采用“像素中心原点”约定：像素 `p` 的坐标是 `p`，其中心在 `p+0.5`，
像素坐标转 UV 时只做一次 `(p + 0.5) / size`。

历史重投影（`ReprojectPixel`）：

```
prevPx = curPx - curJitterPx - velocityPx + prevJitterPx
```

- 速度缓冲以“当前内部分辨率像素/帧”为单位，由当前/上一帧裁剪空间坐标差
  生成，两帧各自的投影抖动在相减时自然抵消。
- 历史纹理携带的是上一帧抖动，必须显式加回，否则历史整体偏移一个子像素。

### 2.3 分辨率与窗口改变

当两个缓冲覆盖同一视口时，归一化 UV（0..1）在两者间天然相同，半像素正确性
由采样器的像素中心约定（`UV = (pixel + 0.5) / size`）保证。因此
`ResizeScaleBias` 的 bias 恒为 0，只在需要跨像素单位（如不同分辨率的抖动
换算）时使用尺寸比。

动态分辨率改变时，历史纹理按旧尺寸保留一帧，重投影 UV 经过尺寸比换算后
参与采样，新结果写入按当前内部分辨率分配的历史集（Ping-Pong 双缓冲），
因此不需要硬清空。空间放大阶段直接用相同的归一化 UV 双线性采样低分辨率
历史即可。

## 3. 遮挡揭开（Disocclusion）

`HistoryConfidence` 联合三项判据，任一失败即拒绝该历史样本：

1. **视口内**：重投影 UV 越界（新揭开区域无历史）。
2. **速度一致性**：邻域最大速度远超中心速度，说明遮挡边界正在扫过该像素。
   判据用绝对阈值（4px）加松弛比值，避免静态轮廓在零中心速度下被误杀。
3. **相对深度一致性**：`|curDepth - histDepth| <= max(0.05, 2% * curDepth)`。
   使用相对而非绝对深度，远处几何不会因大深度值上的浮点噪声被误拒；天空
   （远平面）与天空比较时直接视为一致，天空自身使用相机背景流运动矢量。

被拒绝的像素回退为 100% 当前帧，因此揭开区域不会产生拖影，但代价是该帧
轻微噪声，随后由时域积累在数帧内收敛。

## 4. 历史混合与细线保护

- `MakeNeighborhood` 取当前帧 3x3 邻域，`ClipToAabb` 以邻域均值为中心、
  按 `clipGamma` 收缩 AABB，把历史颜色钳进当前帧统计范围内，抑制鬼影同时
  保留稳定细线。
- `TemporalAlpha` 在名义历史权重上叠加两个衰减：速度越快权重越低
  （`velocityTau` 控制），当前/历史亮度差越大权重越低（细线揭开的
  `smoothstep` 响应）。

## 5. 窗口改变时的历史权衡

窗口/视口尺寸变化会轻微改变取景，但场景内容连续。方案选择**保留历史而非
清空**：坐标映射负责几何对齐，同时把该帧历史置信度乘 0.25
（`windowConfidence`），让新露出的边缘快速收敛、中心区域仍享受时域稳定。
仿真在第 30 帧注入该事件，可观察到单帧闪烁升高、下一帧立即回落。

## 6. 动态分辨率调度

`DynamicResolution` 以 GPU 帧时间目标驱动内部分辨率比例：实测时间超过目标
110% 降一档，低于 80% 升一档，步进 5%，钳在 55%–100%。比例只在帧边界改变，
保证资源分配与历史重映射确定。参考模式固定 100%，用于公平对比。

## 7. 评估方法

三个模式：固定全分辨率参考、无历史双线性放大、新方案 TAAU。

- **边缘误差**：对无抖动的全分辨率稳定真值计算 Sobel 加权 RMSE 与细线
  掩码 RMSE。真值必须无抖动，否则会把“消除抖动噪声”误判为误差。
- **时域闪烁**：相邻输出帧的逐像素颜色差（边缘加权），直接衡量时域稳定性。
- **GPU 时间**：DX11 应用使用 disjoint timestamp 查询（`GpuTimer`，双缓冲
  避免读回阻塞）；仿真台用 ms/百万像素解析模型给出同口径估计。

镜头包含脚本化的相机 yaw 突变（第 20、41 帧）与两条不同深度的细发光线，
分别压测速度突变与细线抗锯齿。
